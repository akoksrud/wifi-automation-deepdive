# 124. Install YANG Suite (optional)

## Installing the YANG Suite Docker Container

SSH into your ubuntu server and run these commands to start the installation (docker is required):

```
cd ~
git clone https://github.com/CiscoDevNet/yangsuite
cd yangsuite/docker
./start_yang_suite.sh
```

The output should look like this. You will have to setup credentials (use the same as the ones in the lab: devnet-adm/ChangeMe2025!):

```
username: devnet-adm
password:
confirm password:
Will you access the system from a remote host? (y/n): y
Enter local host FQDN or IP: 192.168.10.11
email: devnet-adm@test.com

Setup test certificates? (y/n): y
```

From there, you can keep on pressing \[Enter] \[Enter] \[Enter] ...

<mark style="color:$warning;">👉 It will take about 4-5 minutes for everything to get installed.</mark>

When you get to this point, it is ready to run:

<figure><img src="../../.gitbook/assets/image (239).png" alt=""><figcaption></figcaption></figure>

To free-up the command line interface, press CRTL+C to stop YANG suite. Be patient, it will take a few seconds to fully stop and for the prompt to become available again.

Then, to start the container in detached mode, run the following commands:

```
cd ~/yangsuite/docker/
docker compose up -d
```
