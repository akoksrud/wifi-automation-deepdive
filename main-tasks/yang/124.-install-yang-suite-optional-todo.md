# 124. Install YANG Suite (optional)

SSH into your ubuntu server and run these commands to start the installation (docker is required):

```
cd ~
git clone https://github.com/CiscoDevNet/yangsuite
cd yangsuite/docker
./start_yang_suite.sh
```

The output should look like this. You will have to setup credentials (use the same as the ones in the lab: devnet-adm/ChangeMe2025!):

```
username: devnet-adm
password:
confirm password:
Will you access the system from a remote host? (y/n): y
Enter local host FQDN or IP: 192.168.10.11
email: devnet-adm@test.com

Setup test certificates? (y/n): y
```

From there, you can keep on pressing \[Enter] \[Enter] \[Enter] ...

👉 It will take about 4-5 minutes for everything to get installed.
