# Postman

In this lab exercise we will\


* Create a Workspace
* Create an Environment
* Create a Collection
* Test some queries found from yangcatalog.org or YANG Suite (any of your choice)
* Output code to CURL or Python



Note: Postman is also available as a plugin to VS Code. This hands-on lab shows examples from the stand-alone app, but most of the material should be transferrable to the VS Code plugin.
