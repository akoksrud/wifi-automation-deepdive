# 262. Python -> Meraki API

In this exercise we will be using one of the APIs from the Postman collection, as an example we will get the DHCP info from the firewall in this lab. For this request to work you will need to have gathered the serial number of the FW (find it with getOrganizationDevices), and you need your API key. We will start by running the request in Postman, then try to use the Python code that Postman give us for the same request.
