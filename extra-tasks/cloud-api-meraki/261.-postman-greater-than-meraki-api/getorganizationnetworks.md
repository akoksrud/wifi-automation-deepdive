# getOrganizationNetworks

After getting your Org ID, you can get the Networks. You can see that the variable `organizationId` is used as part of the URL

<figure><img src="../../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>

The results will return all then Networks that you have access to. Save the network id of your choice to an environment variable you name `networkId`

<figure><img src="../../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

With this info, you can continue to run other API calls included in the Collection. Follow the same procedure to extract required info that you need as variables in other calls
