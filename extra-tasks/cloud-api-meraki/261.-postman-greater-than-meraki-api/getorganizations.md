# getOrganizations

After obtaining the API key and creating an environment, you can try one of the API calls from the collection you imported

Try running the "getOrganizations" API call. You should get information about the organizations that your user (-> your API key) have access to.

<figure><img src="../../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

API calls in the collection will need different input parameters. Many of them will need the organization ID to run queries for that organization specifically. We will now save the orgID that we got from the getOrganizations API call. Copy the text from "id" and save it in the environment.
