# 223. AI companions

### Various AI companions

You can use various AI Code assistants in VS Code. Some have free tiers, but if you have access to some paid variant you should probably use that. Here are some common alternatives:

* GitHub Copilot (by Microsoft)
  * Some examples and screenshots in this material use GitHub Copilot as it is what I currently have enterprise license to use. It also has a free tier (I have not used that).
* Windsurf  Plugin (by Windsurf)&#x20;
  * Some of the examples in this task use "Codeium" which is the earlier name of Windsurf. The free tier is pretty good in my experience, I used this before having access to GitHub Copilot
* ChatGPT (Codex - OpenAI's coding agent, from OpenAI)
* Gemini Code Assist, or Google Cloud Code (from google.com)
* Claude Code for VS Code (from anthropic.com)

### <mark style="color:red;">**Beware of fake plugins!**</mark>&#x20;

You will generally give access to read lots of stuff to your AI companions, and probably also to change stuff in your code. This is a perfect arena for malicious actors to create plugins that seems to do the intended stuff, but doing malicious stuff in the background! ### Using AI companions

An example of what they can be used for, is documenting your stuff.

It can also help you get your ideas started, to make "boilerplate code". However, beware that generative AI will not always make error-free code, or code that does what you intended. But it will often be a good start, and you can fix the rest yourself

In this exercise, you will open some of the previous scripts, and check out different AI stuff, using your preferred AI assistant. Some examples use Windsurf, some use GitHub Copilot. The look and feel should be similar, except some different hotkeys etc.
